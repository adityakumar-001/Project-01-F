Features that keep attendance honest

Every rule is enforced in the app — no edits after the fact, no fake photos, no outside-store punches.

📸

Front-camera only

Gallery uploads are blocked for punches. Face detection rejects photos without a face.

📍

125m store fence

Haversine distance blocks IN / OUT / Store Close beyond 125 meters — status stays Absent.

⏰

Live time rules

IN 8AM–12PM, OUT until 11:59:50PM, and OUT before 6PM automatically counts as Half Day.

☁️

MySQL cloud sync

The same Admin and Employee IDs work on any device — phone, tablet, laptop or PC.

🎖️

Multi-admin isolation

Each Admin only sees its own Employees and records, stamped with the owner Admin ID.

💾

Backup & export

Download full JSON backups or Excel/CSV reports; restore on any other device in seconds.
